# Project: i151 Grand Master AI Bot (Hyper-Optimization & Benchmark)

## Architecture
The i151 Grand Master Bot is a high-performance, game-theoretically optimal card engine for the i151 Arena competition.
It operates with:
1. **Instant Invariant & Trap Filter**:
   - Zero Queen-alone finishes in 2P games (prevents fatal 1-card forced draw penalty).
   - 1-ply immediate terminal win detection.
   - Valid action structure: play_card has chosen_suit=None; suit selection occurs via choose_suit.
2. **Bayesian Opponent Void Tracking & Starvation (R3)**:
   - Full-round card history and unrevealed pool tracking.
   - Infer opponent void suits whenever an opponent draws and passes or draws and plays.
   - Game-theoretic suit selection when playing an 8, forcing opponent bank draws.
3. **Strategic Resource Preservation & Wildcard Timing (R1)**:
   - Rank 8 wildcards retained as universal counters and emergency escapes when hand size >= 5.
   - Aces preserved for tactical counter-attacks and draw-2 punishment.
   - Aggressive penalty dumping activates only upon genuine round termination (opponent hand <= 3 or self hand <= 2).
4. **Deep Minimax Lookahead & 2-Player Tempo Mastery (R2)**:
   - 5–8 plies iterative deepening Alpha-Beta search with adaptive wall-clock cutoff (target < 50 ms avg latency).
   - 64-bit Zobrist Transposition Table with EXACT/LOWER/UPPER bound flags.
   - Move ordering with TT PV move, winning moves, Queen combos, tactical counters.
   - Minimax value is the primary driver of move selection.
   - Queen tempo combos evaluated with follow-up feasibility to prevent self-inflicted bank draws.
5. **Exact Terminal Endgame Solver**:
   - Exhaustive retrograde / Alpha-Beta search when unrevealed pool <= 6 cards.
6. **Symmetric Unbiased Tournament Verification Suite (R4)**:
   - 50 games vs builtin:medium (25 as p0, 25 as p1) with alternating dealers.
   - Verified reference seeds (848914317, 1477911113, 2063595735, 329389206).
   - Baselines >= 98% vs builtin:random and builtin:basic.

## Interface Contracts
### `benchmark_suite.py` ↔ `bot.py`
- `bot.py` provides `setup()`, `decide(view)`, `observe(view, action, next_view)`, `teardown()`.
- `benchmark_suite.py` executes matches via `play_bots_match` supporting both slot assignments:
  - Role A: `play_bots_match(instrumented_bot, opp.bot, ..., challenger_name="mon-bot", opponent_name=opp_name)` (`my_slot = "p0"`)
  - Role B: `play_bots_match(opp.bot, instrumented_bot, ..., challenger_name=opp_name, opponent_name="mon-bot")` (`my_slot = "p1"`)
- Correct win accounting: `res.winner_id == my_slot`.
- Decision latency tracked per turn; mean must be strictly < 50.0 ms, max < 300.0 ms.

### `bot.py` ↔ `card_tracker.py`
- `CardTracker` tracks cards seen across the entire round.
- `update_from_view(view)` infers opponent void suits when opponent draws (checking previous table top and opponent hand size changes or actions).
- `get_opponent_void_mask()` returns bitmask of suits opponent is void in.
- `get_unrevealed_pool()` returns bitmask and count of unrevealed cards.

### `bot.py` ↔ `evaluator.py`
- `evaluator.py` exposes:
  - `evaluate_state(state, my_idx, streak_mode)` -> float (terminal/leaf evaluation).
  - `score_action(view, action, streak_mode)` -> heuristic evaluation.
  - `choose_best_suit(view, tracker)` -> Suit to declare when playing an 8, forcing opponent void.
  - `finishes_on_queen_two_player(view, action)` -> bool (strictly filters illegal/losing solitary Queen plays).
